# transcript-bot

Telegram-бот, который собирает пересланные в чат сообщения (текст, фото, голосовые,
видео) и по команде `/export` превращает их в один `.md` файл с расшифровкой.

## Возможности

- **Текст** — сохраняется как есть, с указанием автора и даты (в том числе для
  пересланных сообщений — автор и дата берутся из оригинала).
- **Фото** — сначала распознаётся текст на изображении через OCR (Tesseract,
  `rus+eng`). Если текста нет или он слишком короткий, фото отправляется в Gemini
  за кратким описанием сцены.
- **Голосовые и аудио** — распознаются в текст локально через `faster-whisper`.
- **Видео и видео-кружки** — звуковая дорожка так же прогоняется через Whisper.
- **Статьи (rich message / "article")** — новый формат красиво оформленных md-сообщений
  Telegram (заголовки, списки, таблицы, цитаты, вложенные медиа) — разворачивается
  обратно в markdown-текст для лога (см. `bot/rich_message.py`). Требует
  `pyTelegramBotAPI>=4.35.0` (поддержка Bot API 10.1+).
- **Прочие типы** (документы, стикеры, гифки, геолокация, контакты, опросы) —
  фиксируются в логе как факт сообщения, без содержимого.
- Файлы крупнее 20 МБ Bot API скачать не может — такие сообщения попадают в лог
  с пометкой об ошибке, без падения бота.
- Каждый чат хранит свою очередь сообщений независимо (`data/<chat_id>/`).
- Сообщения в экспорте всегда идут в порядке пересылки (по `message_id`), даже
  если обработка фото/голосовых/видео заняла больше времени, чем у соседних
  текстовых сообщений.
- Итоговый `.md` файл называется `transcript-DD.MM.YYYY-companion1-companion2-...md`,
  где дата — дата экспорта, а имена собеседников — их настоящие имена аккаунтов
  (`имя фамилия`, без `@username`), в порядке первого появления в переписке.

## Команды бота

| Команда         | Действие                                                              |
|-----------------|------------------------------------------------------------------------|
| `/start`, `/help` | Показать приветственное сообщение (текст берётся из `welcome.md`). |
| `/status`         | Сколько сообщений уже накоплено в текущем чате.                    |
| `/export`         | Собрать `.md` файл, прислать его и сразу очистить накопленное (эквивалент `/clear`, включая скачанные медиафайлы). |

Все команды также закреплены кнопками на клавиатуре чата (появляется после
первого `/start` или `/help`), так что их не нужно печатать вручную.
| `/clear`          | Очистить накопленное без экспорта.                                 |

## Приветственное сообщение

Текст, который бот отправляет на `/start` и `/help`, хранится отдельно от кода —
в файле [`welcome.md`](welcome.md). Его можно свободно редактировать: файл
читается заново при каждом вызове команды, перезапуск бота не требуется.

Путь к файлу задаётся переменной окружения `WELCOME_FILE` (по умолчанию
`./welcome.md`). В Docker-варианте файл примонтирован volume'ом
(`docker-compose.yml`), поэтому его можно менять прямо на сервере — изменения
подхватятся мгновенно, без пересборки образа.

## Установка и запуск

### Локально

1. Установите зависимости:

   ```bash
   pip install -r requirements.txt
   ```

2. Скопируйте `.env.example` в `.env` и заполните переменные (как минимум
   `BOT_TOKEN` — токен, выданный [@BotFather](https://t.me/BotFather)):

   ```bash
   cp .env.example .env
   ```

3. Запустите бота:

   ```bash
   python main.py
   ```

Для OCR понадобится установленный Tesseract (`tesseract-ocr`, языковой пакет
`rus`); на Windows путь к бинарнику указывается через `TESSERACT_CMD`.

### Docker

```bash
docker compose up -d --build
```

Данные (`./data`), кэш модели Whisper (`./hf_cache`) и `welcome.md`
примонтированы как volume'ы — они переживают пересборку образа.

## Переменные окружения

| Переменная            | По умолчанию      | Описание                                                        |
|------------------------|--------------------|-------------------------------------------------------------------|
| `BOT_TOKEN`             | —                  | Токен бота от @BotFather. Обязателен.                            |
| `WHISPER_MODEL_SIZE`    | `base`             | Размер модели faster-whisper.                                    |
| `WHISPER_DEVICE`        | `cpu`              | Устройство для инференса (`cpu`/`cuda`).                         |
| `WHISPER_COMPUTE_TYPE`  | `int8`             | Тип вычислений faster-whisper.                                   |
| `TESSERACT_CMD`         | (пусто)            | Путь к бинарнику Tesseract, если он не в `PATH` (актуально для Windows). |
| `OCR_LANGS`             | `rus+eng`          | Языки распознавания OCR.                                         |
| `OCR_MIN_CHARS`         | `15`               | Минимум символов OCR, при котором Gemini-описание не запрашивается. |
| `GEMINI_API_KEY`        | (пусто)            | Ключ Gemini API ([бесплатно](https://aistudio.google.com/apikey)) для описания фото без текста. |
| `GEMINI_MODEL`          | `gemini-2.0-flash` | Модель Gemini.                                                   |
| `DATA_DIR`              | `./data`           | Где хранить очереди сообщений и скачанные медиафайлы.            |
| `WELCOME_FILE`          | `./welcome.md`     | Путь к файлу с текстом приветственного сообщения.                |

## Структура проекта

```
main.py              — точка входа, запуск polling
bot/config.py         — чтение конфигурации из окружения
bot/handlers.py        — обработчики команд и типов сообщений
bot/session_store.py   — накопление сообщений и медиафайлов чата в data/<chat_id>/
bot/transcriber.py      — распознавание голоса/видео через faster-whisper
bot/vision.py           — OCR + Gemini-описание фото
bot/rich_message.py      — разворачивание rich message ("статей") в markdown
bot/md_export.py         — сборка итогового .md файла
welcome.md               — текст приветственного сообщения (/start, /help)
```

## Деплой

`.github/workflows/deploy.yml` при пуше в `main` подключается по SSH к VPS
(секреты `VPS_HOST`, `VPS_USER`, `VPS_SSH_KEY`, `VPS_PATH`) и выполняет
`git pull && docker compose up -d --build`.
